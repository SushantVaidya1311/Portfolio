# Sushant Vaidya — Portfolio

A responsive, frontend-only portfolio built with React, JavaScript, and Vite.

## Run locally

Requires Node.js and npm.

```sh
npm install
npm run dev
```

Create a production build with `npm run build`, or preview it locally with
`npm run preview`.

## Personalize

Update the project details, contact email, social links, and about copy in
`src/App.jsx`. Page layout, colors, responsive behavior, and theme styles are
in `src/styles.css`.
